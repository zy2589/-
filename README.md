# 剪辑助手

Windows 桌面应用，主窗口提供“下载区域”“剪辑区域”“抠图区域”“拼接区域”四个入口，采用统一的深色、紧凑圆角控件风格。

## 功能

- **下载区域**：内置下载助手页面，保留人名、号码、标题、引流模板 1、保存位置和固定显示的 12 行任务表；下载后的降噪支持全局及逐行设置。
- **剪辑区域**：由剪辑助手主进程直接承载 WebView2 剪辑界面，沿用工程创建、工程卡片、剪辑命令和纠错功能；不另开 Edge 浏览器窗口或剪辑宿主 EXE。编辑器仍使用隐藏的本地服务进程处理媒体和工程操作。Gemini/API 登录与设置仅供剪辑区域的纠错功能使用。
- **抠图区域**：主窗口内提供 1–5 五个独立页面，每页可单独导入视频；抠图后台运行，隐藏终端窗口。
- **拼接区域**：复用剪辑工作区的素材区、预览、时间轴和导出流程。支持上下、三分区、四分区、斜切与多个可拖动画中画区域；可分别指定视频分区、描边样式，以及正常有声、静音播放、定格后恢复或定格到片段结束。
- **本地媒体**：下载、降噪、剪辑、拼接与抠图都使用应用随包提供的本机运行组件和用户选择的本机素材，不要求安装其他助手软件。
- **交互样式**：各页面统一按钮尺寸、深浅状态和滚动条；音频片段统一暗绿色底、白色波形；列表和画布支持滚轮操作。

## 本机数据

安装程序位于 `%LOCALAPPDATA%\Programs\剪辑助手`。工程、账号/API 配置、编辑预设和下载偏好设置保存在 `文档\ChatGPT\剪辑助手\用户数据` 中；下载视频与导出文件保存在你选择的位置。

安装与运行都只使用“剪辑助手”自己的程序文件和 `文档\ChatGPT\剪辑助手\用户数据` 数据目录，不读取、复制或迁移其他软件的程序或本地数据。删除旧软件和旧数据目录不会影响本软件；请保留本软件自己的数据目录。

## 安装与构建

- 安装：运行 `安装剪辑助手.bat`。
- 构建：运行 `build.ps1`，输出到 `release\剪辑助手`。剪辑首页源码、Node 运行时、WebView 控件、模型和媒体引擎都来自当前项目目录；C# WebView 宿主编译为 DLL 并由主程序同进程加载。构建不访问其他助手的安装目录。
- 安装位置：`%LOCALAPPDATA%\Programs\剪辑助手`，并创建开始菜单快捷方式。

## 项目目录与文件归档

- `core/`：应用源码和内置编辑器源码。
- `assets/`、`resources/`：应用界面资源、媒体引擎和模型等随包资源。
- `用户数据/`：本机工程、运行配置、日志和下载设置；需要保留，不用于放源码或发布包。
- `.venv/`：开发和构建使用的 Python 环境；`build.ps1` 和启动脚本依赖它。
- `.build/`：构建过程中的临时文件，由构建脚本管理。
- `release/`：构建生成的可安装程序包；保留给本机安装或备份，不提交到源码版本。
- `docs/`：操作说明、修改记录和参考图片。
- 项目根目录只放启动/安装/构建入口、依赖清单和项目总览。

新生成的构建中间件放入 `.build/`，发布包放入 `release/`，应用设置和工程数据放入 `用户数据/`。下载与导出文件仍保存到用户在软件中选择的位置；应用创建的临时处理文件会使用目标目录中的专用临时前缀并在完成后清理。不要把工程成品、日志、缓存或临时媒体放进 `core/`、`assets/` 或 `resources/`。开发启动入口已关闭 Python 字节码缓存生成；已有缓存可安全忽略，后续不会继续散落。
