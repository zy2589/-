# 剪辑助手

Windows 桌面应用。主窗口目前有三个入口：**下载区域、剪辑区域、抠图区域**。

## 功能

- **下载区域**：固定显示 12 行任务，支持按人名、号码、视频名称和可选链接分别创建任务。下载完成后再按规则压缩，并按所选设置降噪；下载阶段不额外合并分离的音视频流。只在下载区域置顶，切换到其他区域会取消置顶。
- **剪辑区域**：管理视频和音频轨道，可裁切、静音、调色、调整画面位置与大小，并提供上下分区、多分区、斜切和多个画中画等布局。
- **抠图区域**：提供两个独立页面，可分别导入和处理视频。

## 账号和 API 凭证

从软件设置中保存的 Gemini、Vertex、Groq、Deepgram API 密钥，以及 Vertex 服务账号 JSON，使用 Windows DPAPI 按**当前 Windows 用户**加密后保存。应用设置中的模型、服务商、项目编号等普通配置保存在 JSON 文件中，不属于凭证加密范围。通过系统环境变量提供的 API 密钥由 Windows 环境配置管理，软件不会再次加密。

DPAPI 凭证与当前 Windows 用户配置关联。迁移到其他 Windows 用户或电脑时，原凭证通常无法直接解密，需要在新环境重新配置。Antigravity 登录由外部 `agy` 工具管理；本应用保存工具路径，登录凭证由该工具处理。

## 数据位置

- 安装目录：`%LOCALAPPDATA%\Programs\剪辑助手`
- 工程、应用设置、运行配置和凭证：`文档\ChatGPT\剪辑助手\用户数据`
- 下载和导出文件：保存在软件中选择的目标目录

安装、运行和构建使用本项目自带的应用组件与用户选择的媒体文件，不读取、复制或迁移其他剪辑软件的工程或程序数据。请保留本软件自己的“用户数据”目录，以免丢失工程、设置和凭证。

## 安装、运行与构建

- 安装：运行 `安装剪辑助手.bat`。
- 在本项目工作区直接运行：运行 `运行剪辑助手.bat`。源码启动器会优先查找构建输出中的剪辑内核；如果项目中尚无构建输出，请先运行 `build.ps1`。
- 构建：运行 `build.ps1`，输出到 `release\剪辑助手`。安装位置为 `%LOCALAPPDATA%\Programs\剪辑助手`，并创建开始菜单快捷方式。
- 代码签名：当前发布的主程序 EXE 尚未使用受信任的代码签名证书签名。启用了 Windows 智能应用控制的电脑可能会拦截该 EXE；本工作区的 `运行剪辑助手.bat` 可通过已签名的 Python 运行环境启动源码，但这需要保留本项目的开发环境和构建内核。正式分发前仍需接入可信签名并重新发布。

## 项目目录与文件归档

- `core/`：应用、下载器和编辑器源码。
- `assets/`、`resources/`：界面资源、媒体引擎、模型和运行时资源。
- `用户数据/`：本机工程、运行配置、日志和下载设置；需要保留，不用于放源码或发布包。
- `.venv/`：开发与构建使用的 Python 环境。
- `.build/`：可重新生成的构建中间件，由构建脚本管理。
- `release/`：构建生成的程序包，供本机安装或发布使用；不提交到源码版本。
- `docs/`：操作说明、修改记录和参考图片。

根目录只保留项目总览、依赖清单、程序入口和安装/运行/构建脚本。新生成的中间文件放入 `.build/`，发布包放入 `release/`，工程数据放入 `用户数据/`。下载与导出文件仍保存到软件中选择的位置。
