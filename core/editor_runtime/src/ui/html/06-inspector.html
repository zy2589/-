视频播放方式

每段素材独立控制；默认同时按时间线播放并带声音，需要时单独静音或定格。

先在时间线上选中视频片段。截取首帧后自动存入素材区，并按该轨道前方空档的实际时长填入；没有空档时只存入素材区。

定格期间画面保持所选帧，关联声音静音；恢复点之后按时间轴继续播放原片段。
