## 主窗口区域切换闪烁（结构性修复已完成，待实机确认）

- **记录日期：** 2026-11-15
- **现象：** 软件启动时有明显刷新；下载、剪辑、抠图区域切换时仍闪烁，尤其是下载与抠图来回切换。
- **期望：** 三个区域留在同一个主窗口，切换不黑屏、不闪白、不重建页面，并保留页面状态。
- **结构核查：** 下载区与抠图区由同一个 Tk 根窗口承载；抠图 `RotoscopeWindow` 使用传入的 Tk `host`，正常嵌入时不新建顶层窗。剪辑区由同进程 WinForms/WebView2 子 HWND 承载，另有本地 Node 服务；它不是第二个顶层应用窗口，但渲染窗口类型与 Tk 页面不同。
- **源码根因：** 主窗口三个页面 Frame 曾同时 `grid()` 映射，只通过 `tkraise()` 改堆叠；抠图内部两页也同时映射。隐藏页面仍可能收到 `Configure/Expose` 并重绘。启动 600 毫秒后还会在 UI 线程创建抠图整套控件；抠图隐藏时收到预览帧仍会执行 LANCZOS 缩放、`Canvas.delete('all')` 和完整重画。这些额外绘制与 UI 线程负载会造成切换抖动/刷新感。
- **与剪辑页的关系：** 历史上曾因 WebView2 宿主跟随 Tk 页一起取消映射会出现空白，所以保留了所有页面映射。`432b593` 已把 WebView2 HWND 调整为 `page_stage` 下与 Tk 页面同级；现在页面可以按需取消映射而不销毁实例，旧的“所有页面一直映射”规避方式不再需要。
- **录屏与旧日志：** `屏幕录制 2026-11-15 102550.mp4` 约 30 fps 抽帧检查，区域转换发生在相邻帧内，未采到整屏黑/白帧；这无法排除小于一帧的短闪。旧版桌面日志每次只见一次 WebView 初始化/就绪，没有 renderer 崩溃或恢复记录，但当时没有页面切换和导航计数，因此不足以定位短闪。
- **本次修复：** 主窗口只映射当前区域；切换时先映射并提升目标页，再隐藏旧页，页面对象不销毁，状态和 WebView 均保留。抠图内部只映射当前子页。取消启动后隐藏创建抠图整套控件，改为用户首次进入时按需加载。抠图隐藏期间仍处理任务和接收解码结果，但合并预览重画，恢复显示时只补画最新帧。下载/剪辑/抠图的业务实例未在普通切页时销毁。
- **新增诊断：** 每次区域切换记录页面映射、尺寸、Tk 句柄和有限时间内的 `Map/Unmap/Configure/Expose` 事件；记录抠图控件构建/导入耗时，以及预览帧被延迟还是实际重画和绘制耗时。日志写入 `用户数据/运行配置/logs/ui-page-*.log`。剪辑宿主日志额外记录 WebView 导航开始/完成和子窗口层级变化，不写入导航 URL 或会话令牌；路径为 `用户数据/运行配置/logs/desktop-*.log`。
- **验证：** Python 编译通过；Tk 页面切换冒烟检查完成 12 次区域往返，确认每次只有目标页使用 `grid`、原页面 HWND/实例 ID 保持不变；抠图两页来回切换检查通过；页面诊断日志检查通过；剪辑 WebView C# 宿主单独编译通过；`git diff --check` 通过。当前环境未执行安装版的可视化人工连点，因此不把“用户机器上的体感闪烁已消失”写成已实机确认。
- **参考原理：** [Tkinter 事件循环与 `after`](https://docs.python.org/3/library/tkinter.html)、[WebView2 线程模型](https://learn.microsoft.com/microsoft-edge/webview2/concepts/threading-model)、[Windows 同级窗口与 Z 顺序](https://learn.microsoft.com/windows/win32/winmsg/window-features)、[`SetWindowPos` 重绘行为](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-setwindowpos)。
- **处理状态：** 源码结构性修复与编译/冒烟检查已完成；尚未打包或安装。安装后的真实切换若仍闪，新增 UI 与桌面日志可直接判断是否页面重映射、WebView 重导航、异常重建或预览重复绘制。

- **现象：** 下载最佳分离音视频流后，yt-dlp 会在下载阶段调用 FFmpeg 合并；小于 80 MB 的文件也会额外转成 MP4。

- **处理状态：** 下载选用单个含音画的现成格式，不再在下载阶段合并；下载完成后才压缩、降噪。
