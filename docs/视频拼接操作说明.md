# 拼接布局操作说明（剪辑区域内）

本说明介绍剪辑器中的分区布局和画中画操作。

## 导入与放置素材

1. 在主窗口左侧打开“剪辑区域”，新建或打开工程。
2. 在剪辑器中打开“拼接”面板，选择画面布局；素材仍从剪辑器的素材区导入和管理。
3. 单击素材只用于选择。将视频、图片或音频从素材区拖到对应时间轨道，才会放进工程。
4. 视频和图片放在视频轨，音频放在音频轨。轨道与片段都在同一条剪辑时间线上管理。

## 分区和画中画

1. 可选上下分区、上二下、上下一、四等分、斜切分区或画中画布局。布局用于确定画面区域，素材的起止时间仍由时间线片段控制。
2. 上下分区可拖动中间分割线调整比例；斜切布局还可调整斜切角度。
3. 可添加多个画中画区域，分别调整区域的位置、大小、形状及描边。布局面板控制画中画外框；素材本身的缩放、位置等变换在属性面板调整。
4. 预览中选中画中画后，可拖动画框调整外框位置；需要调整框内视频构图时，选中对应素材并使用属性变换，避免把外框和素材变换混为一项。
5. 图片作为独立图层放在拼接视频之上，不会因为拖到分区里而被绑定成该分区的视频。图片在时间线上设置显示区间，并可单独调整预览位置和大小。

## 时间线、播放和截帧

1. 选中时间线中的视频片段后，可设置正常播放并带声音、正常播放但静音、选帧定格后继续播放，或定格到片段结束。
2. 静音、裁切和局部变换通过时间线片段及对应属性进行，不要求所有视频采用相同的说话/静止角色。
3. 需要截帧时，先选中目标视频片段，再执行截帧命令。截取帧按所选片段处理，并尝试放到同轨片段前方的空隙中；没有空隙时不覆盖已有片段。
4. 预览画面应与播放头和时间线片段范围同步；播放头超出素材有效区间时，该素材不应继续显示。

## 导出

拼接工程从剪辑区域右上角的“导出视频”进入导出流程。导出范围、画面布局、轨道层级、图片覆盖层和音频应与当前时间线预览保持一致。
