# 视频拼接操作说明

## 导入与放置

1. 在左侧点击“拼接区域”，新建拼接工程。
2. 将视频、图片或音频导入左侧素材区。单击素材只会选中它；把素材拖到预览画面或时间线，才会加入工程。
3. 视频和图片放到视频轨（V 轨），音频放到音频轨（A 轨）。拖放位置落在另一种轨道上时，软件会改放到对应类型的新轨道。
4. 拖到时间线上方的空白位置会自动新建轨道。时间线上同一轨道的片段按覆盖、插入或置顶模式处理。

## 分屏和画中画

1. 在右侧“拼接”面板选上下分区、上下二、上下一、四等分、斜切分区或画中画。预览画面会立即更新。
2. 上下分区可直接拖动中间分割线调整比例；斜切分区先拖分割线调整比例，再用“斜切角度”控制角度。
3. 画中画可以添加多个。新画中画会优先放到空位置，避免遮住已有画中画。
4. 将视频拖到对应分区即可填入该分区。把图片拖到预览画面时，图片会作为独立覆盖层放在全部拼接视频上方，不会被绑定到鼠标所在的分区；可在时间线上调整显示区间，并在预览画面里移动、缩放图片。
5. 画中画里面有视频或图片时，在画面中间拖动可调整素材构图；沿画中画边缘拖动可移动画中画框。空画中画可直接在框内拖动。
6. 选中画中画后，在“拼接”面板选择形状、描边颜色和宽度。描边至少 10 px；预览和导出采用相同设置。
7. 移动画中画框或缩放/移动框内素材时，画面会限制在画布与对应分区范围内。

## 时间线、声音与定格

1. 在预览画面单击视频、图片或文字，会同步选中时间线片段；片段不在当前滚动位置时，时间线会自动滚到它的位置。
2. 在时间线上选中视频后，可在“拼接”面板设置正常播放并带声音、正常播放但静音、选择一帧定格后继续播放，或定格到片段结束。
3. 选中一个视频片段后，点击“截取片段首帧并填入前方空档”，软件会取该片段源视频的第一帧放进素材区，并尝试填满同轨道片段前方的空隙；没有空隙时只保存到素材区，不覆盖已有片段。
4. 位置、缩放、旋转、不透明度和裁切位于“属性”面板。位置既可输入数值，也可拖动 X/Y 滑块。画中画中的素材也可直接在预览里拖动。
5. 音频片段使用暗绿色底色、白色波形；静音、选中和范围提示仍由原有标记显示。

## 导出

完成时间线、分区和属性调整后，点击右上角“导出视频”，按剪辑区域相同的导出流程设置格式与输出位置。

## 本轮修改记录

- 左侧四项统一命名为“下载区域、剪辑区域、抠图区域、拼接区域”。
- 移除了工程首页和编辑页右侧重复的品牌标题。
- 共用的 X/Y 滑块、预览/时间线选中联动和 V/A 轨自动分配已加入剪辑区域与拼接区域。
- 修正画中画描边样式被固定 CSS 覆盖的问题，新增画中画采用错开位置，保存和拖动时限制在画布内。
- 画中画内部拖动编辑素材，拖动描边移动区域；预览移动改为直接更新变换，避免拖动时反复重建整个预览。
- 统一两种页面的音轨暗绿色底色与白色波形。
