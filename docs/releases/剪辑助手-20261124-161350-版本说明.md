# 剪辑助手 v20261124-161350

## 本版本变更

- 字幕识别与文案对齐以局部上下文和正确文案为依据；低置信度或无法确定的候选进入人工复核，不凭整篇文案远距离补词。
- 文案外口语进入“待确认”，由用户试听后选择剪除，或保留声音并添加字幕；剪除支持微调边界和剪后试听。
- 收紧远距离重复片段判断，修正数字和经文格式等价、相近读音误标，并保留手动更改结果。
- 增加 Logi MX Master 4 Actions Ring 快捷键设置清单和说明。
