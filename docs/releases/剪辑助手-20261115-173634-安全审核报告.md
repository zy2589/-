### 修复和剩余风险

- **已修复：** 打包态 UI 构建检查原先只按源码目录定位下载器文件，导致复制后的构建阶段失败；现在同时识别源码树和暂存包目录，完整构建成功。
- **本轮修复：** 移除下载、剪辑、抠图主页面及全局工具弹窗的强制置顶；构建门禁扫描源码，构建版和安装版主窗口扩展样式均验证没有 `WS_EX_TOPMOST`。
- **仍需注意：** 用户提供的下载链接会触发外部网络请求；媒体解码器处理用户选定的文件。只下载可信来源并处理可信媒体。AI/语音功能启用时，媒体或文本是否发送给服务商取决于所选功能和服务配置。
- **用户操作：** 无需因本次安全扫描轮换密钥。API 密钥请仅在受信任的 Windows 用户账户下保存；不要把用户数据目录加入版本库或分享给他人。
- **审核结论：** 本次构建和有限范围的依赖/秘密扫描未发现严重、高或中等级别问题，适合在该 Windows 环境本机安装。它不是完整渗透测试；复杂剪辑布局、全部导出路径和真实网络服务未全部验收，不能据此声称所有功能均无缺陷。
