# 打包前回归复检清单

每次生成安装包或便携包前，先执行 `build.ps1` 的自动静态门禁，再按本表用当前构建实际操作。近期同一类回归反复出现；静态代码检查通过不等于界面行为通过。任一项失败或未验证，都先停在本地修复，不生成可交付版本、不安装、不上传。

| 检查项 | 实际操作 | 通过标准 | 记录方式 |
|---|---|---|---|
| **P0 文案删除隔离** | 在工程副本中删除一个重复提示对应字幕；覆盖同一字幕对象里有未选中词、同一 issue ID 复用于其他时间段/轨道、区间前后还有文案，以及缺少逐词时间信息的字幕；保存并重新打开工程复查 | 只移除选中 issue、时间、轨道和所属素材范围内的词；同组其他词、其他时间段/轨道全部保留；无法精确定位或会清空全部文案时取消操作；重开后仍保留 | 记录工程副本、issue ID、所属轨道/素材、各时间码、删除前后文案数量和重开结果 |
| 剪辑工作区 WebView2 启动 | 冷启动后进入剪辑工作区；再关闭并重开一次；覆盖主配置和恢复配置启动路径 | 每次都出现编辑器首页，日志包含 `NAVIGATION_COMPLETE` 与 `DESKTOP_READY`；不显示 `E_UNEXPECTED` 启动失败 | 记录构建标识、profile 路径类型、启动日志及首页截图 |
| 主窗口切换与启动刷新 | 冷启动；下载、剪辑、抠图连续往返切换两轮 | 不出现黑屏、闪白、整页重载或第二次内容重建；下载页与抠图页状态保留；日志中切页无 WebView 再导航 | 记录启动及切页日志，必要时录屏 |
| 轨道层级与预览合成 | 放置不同视频到多个视频轨；测试上下、上二下、上下一、四分区、斜切和画中画；播放、拖动播放头并调换轨道顺序 | 预览中同一时刻的上层/下层关系与时间线一致；没有强制置顶；导出顺序与预览一致 | 保存最小复现工程并记录时间码 |
| 空白区、素材边界与定格 | 在素材开始前、结束后、轨道间隙和分区空位播放/逐帧；测试定格片段边界 | 没有素材的地方不显示旧帧、预生成帧或占位文字；素材结束后立即消失；定格只在设置的片段范围内显示 | 记录轨道、时间码及预览截图 |
| 切片、修剪与轨道移动 | 在剪辑区域切片；测试片段中间、首尾边界；视频/音频跨轨拖动、覆盖和插入 | 切片命中正确片段且两段边界准确；拖动不串轨、不丢音画、不生成重复片段；剪辑页切片功能可用 | 记录操作方式和复现工程 |
| 截帧填充空隙 | 选中不同视频片段，截取当前帧；分别在前方 1、2、3 秒空档执行 | 使用所选片段的帧；静帧只填充该片段前的空档到片段起点，不叠加、不覆盖邻片 | 记录源片段、空档时长和结果 |
| 画中画与预览锚点 | 选中画中画外框移动/缩放，再选内容调整位置/缩放/裁切；改形状、描边色和宽度；切换上下分区检查上、下每个区域 | 外框与内容分别由对应控件控制；画面、滑块和锚点同步；选择框不过粗、不越界；无素材区域不残留旧画面或说明文字 | 记录每种布局与截图 |
| 时间线布局与文字 | 拖动轨道高度、视频/音频分界、素材区/时间线分界；拖放图片/视频/音频；检查轨道名和持续时间 | 分界可拖且预览仍可用；媒体落入正确类型轨道；需要时自动新增轨道；文字能适配，不挤压成重叠或乱码 | 记录窗口尺寸和轨道高度 |
| 音频轨显示 | 检查剪辑音频片段及波形 | 暗绿色片段底色、白色波形，选中态仍清晰 | 截取时间线截图 |
| 标题关键字高亮 | 自动生成不同标题，并手动增加/取消其他词的高亮 | 仅 GOD、JESUS、Holy Spirit 自动橙色高亮；其他词按手动设置 | 记录输入标题与结果 |
| 下载、命名和后处理 | 用不同人名/标题测试同链接、无链接、同标题不同人名；执行标题图生成；检查保存目录和下载后处理 | 12 行显示正常；文件归入“人名 + 视频名称”文件夹；标题图不是空目录；下载阶段不合并音视频，下载后才压缩/降噪 | 检查实际输出文件、大小和路径 |
| 压缩保留原始方向 | 分别压缩横屏、竖屏和带 90°/270°旋转信息的视频；检查输出画面尺寸、显示方向和比例 | 输出保留源素材横竖方向与比例；不出现固定竖屏画布、黑边或拉伸；压缩仍降低文件大小；源文件仅按原有选项处理 | 记录输入/输出探测规格及文件大小 |
| 导出 | 从包含视频、图片、音频、分区/画中画的工程导出；另测素材失联 | 正常工程产出可播放且含预期画面/声音的视频；失联时给出明确素材路径和重关联指引，不显示“完成”但无文件 | 记录导出设置、结果文件和错误日志 |
| 窗口层级 | 切换下载、剪辑、抠图和工具弹窗，再切到其他应用 | 软件主窗口和弹窗均不强制置顶；普通所属窗口关系仍可正常使用 | 检查窗口扩展样式并记录切换结果 |
