# 打包前回归复检清单

每次生成安装包或便携包前，先执行 `build.ps1` 的自动静态门禁，再按本表用当前构建实际操作。近期同一类回归反复出现；静态代码检查通过不等于界面行为通过。任一项失败或未验证，都先停在本地修复，不生成可交付版本、不安装、不上传。
